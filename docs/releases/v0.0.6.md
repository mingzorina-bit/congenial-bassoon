## 2026-10-07 项目级密钥配置补充

仓库根目录现提供 `.env.example`，本机 `.env` 由 Git 忽略。WinUI Host 在创建 OpenAI provider 前读取项目根目录 `.env`，但不覆盖已有进程环境变量；缺少文件、缺少变量或空值时继续本地输入并给出非敏感提示。自动测试覆盖文件加载、环境优先级、缺失/空值和无 Key provider 错误；本次 Host 17、Onboarding 7、Details 22、Learning 13、Expression 10、Provider 19，共 88 项本地 C# 回归通过，短路径下 WinUI Release 构建 0 警告/0 错误。真实 API 语义仍需用户本机填写 Key 后按语义清单人工验证。
