# v0.2.2 Phase 1-A TSF build review

Status: **build and module tests passed; external-editor trial pending signing and installation review**. This is not a Phase 1-A acceptance PASS.

The separate Windows x64 package contains `BilingualTsf.dll`, the approved local Rime engine/data, a five-candidate desktop popup, a narrow per-user registration helper, default dry-run registration/removal scripts, source notices, and a SHA-256 file inventory. It does not modify the existing WinUI v0.2.1 trial. The TSF DLL excludes cloud, learning storage, surrounding-text collection, and global hooks. Tab and Shift+Enter are passed to the host.

CI run [38222256758](https://github.com/mingzorina-bit/congenial-bassoon/actions/runs/38222256758) passed native Core/TSF tests, real Rime tests, Host tests, packaging, and source/inventory audit. Its separate artifact is [11735770561](https://github.com/mingzorina-bit/congenial-bassoon/actions/runs/38222256758/artifacts/11735770561), with GitHub-reported digest `sha256:a41aa7e38b1e797db6d200bbcf1af4a75460b6eb5fc1a453d3d54f095d4ac98f`. Later signing-gate edits require a fresh CI run before this becomes final evidence.

Microsoft's [IME requirements](https://learn.microsoft.com/en-us/windows/apps/develop/input/input-method-editors) require third-party IMEs to be digitally signed. The CI artifact is unsigned. `Register-TsfTrial.ps1 -Apply` rejects an untrusted TSF DLL, Rime DLL, or registration helper. Signing changes file hashes, so the included `Seal-SignedTsfTrial.ps1` rebuilds the inventory and audits a new ZIP after trusted signing. No registration or activation was performed in CI or on the user's PC.

Remaining gate: establish a trusted code-signing route, review the signed package and precise rollback, then explicitly register for a manual Notepad and second-editor trial. Verify Space, Enter, Esc, candidate highlight, focus loss, removal and restoration of the prior keyboard; verify that a password field shows no candidate or retained text. UI-less/app-container hosts and full bilingual Shadow/Details are outside this narrow spike.
