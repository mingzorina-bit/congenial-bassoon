# v0.1.0-alpha integration candidate

This milestone integrates the approved v0.0.6 AI demo-mode and project-level key configuration without changing frozen input behavior. The package script now names the alpha artifact and checks every packaged file against its SHA-256 inventory, requires source notices and rejects unreviewed data paths or `.env`. CI runs the same audit before upload.

Acceptance record: `tests/manual/phase0-acceptance.md`; three decisions: `docs/reviews/phase0-gates.md`. CI, package hash, clean-machine launch, measured latency and 10–20 minute human trial must be filled with actual results. Real OpenAI semantics remain PENDING while the account has no API credit; Mock cannot satisfy AC-13. This is a trial candidate, not Phase 0 completion or commercial release.

The current authored Rime and lexical fixtures are intentionally small. Phase 0 permits an independently reviewed CC-CEDICT subset and an ECDICT candidate import with provenance, but adding either requires a concrete source/version/rights/redistribution proposal and approval under A-18. A separate lexicon-expansion milestone after alpha is recommended; Microsoft-Pinyin-scale coverage and production commercial dictionaries are AC-29 out of scope.
