# v0.0.1 Candidate Foundation — 试用验证记录

日期：2026-09-21。产品基线为五份冻结规格及 CR-01～05；本轮只实现 Candidate Foundation。用户已批准依赖并要求达到可试用程度后暂停收集反馈。

## 范围与工程证据
- C++20 InputSession、真实 librime adapter、C ABI、WinUI 3 编辑区、候选高亮/选择、主题切换。
- 14 项 Core 测试、17 项 Host 按键路由测试通过；真实 Rime 测试验证 youhua/xuexi/gongzuo/zhongguo、空格选择、Enter 原文、残余拼音不丢失。
- 首次 Core 测试曾有 12 项预期失败；实现后全部通过。标点/数字路由回归先观察到 8 项失败，修复后 17 项通过。
- 发布目录缺少 WinUI 资源造成启动失败，已修复为显式发布 XBF 和 resources.pri，并加入打包缺失检查。新目录发布后本机实际启动成功，无需 API Key。
- CI 编译机器 windows-2022；本机独立执行 Core/真实 Rime/Host routing 测试通过。最终 CI 与试用包见 PR #1 的 c05b7a5 构建。
- 隐私扫描移到 Rime finalize 后，覆盖退出时可能发生的落盘；没有云端实现、用户词典学习禁用、无输入内容日志。

## 实际窗口验证
在本机已启动的发布目录执行真实键盘/鼠标操作：
- youhua 出现 优化/油画/有话。
- Right 高亮 油画，Space 提交 油画，composition 清空。
- 再次逐键输入 youhua，Enter 后编辑器追加原文 youhua。
- y 的第三候选 有，鼠标点击后正确追加。
- 再次输入 y，按 2 正确追加第二候选 以。
- 深色切换浅色后编辑内容保留，候选与文字可辨。

以上是工程冒烟证据，不替代用户连续 10–20 分钟 UX 验收。

## 依赖与部署
- 采用用户明确授权的备用仓库 mingzorina-bit/congenial-bassoon（公开）。连接器没有创建仓库方法，浏览器创建页失败；未宣称已创建私有 BilingualInput。
- 原始会话快照保留在本地 docs/source，不上传公开仓库。
- librime 官方预编译 rime.dll 带 GPL 插件，因此不分发；使用固定 1.13.1 源码关闭插件和日志构建。
- 固定 Boost 1.84.0、.NET SDK 8.0.425、Windows App SDK 1.8.260804001；具体来源、摘要、许可见 THIRD_PARTY_SOURCES.md 与包内 licenses。

## 当前结论与保留项
可进入首个里程碑试用；不宣称完整 Phase 0 或所有 AC PASS，不自动进入 v0.0.2。
- 尚需用户 10–20 分钟体验与另一台干净 Windows 机器验证。
- 有限自有词表约 90 条，不代表成熟输入法覆盖率。
- 只在自身编辑区工作；Shadow、onboarding、Hover、Learning、AI、TSF 未实现。
- 窗口过度缩小时编辑区可能被挤压，当前建议最大化试用；多 DPI、小屏布局仍待完善。
- 当前主题设置只在本次会话生效；完整设置与 onboarding 持久化留在后续计划。
- 未做签名、商店和商业发行；不将原型许可审核当作最终商业授权。

下一步：收集候选跟手程度、空格/Enter/方向键习惯、候选布局反馈，经本阶段验收后才开展 Shadow。
