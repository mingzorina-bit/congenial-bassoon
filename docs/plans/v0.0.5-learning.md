# v0.0.5 Learning implementation

Approved dependency: Microsoft.Data.Sqlite 8.0.31 with its pinned SQLitePCLRaw/e_sqlite3 transitives, no ORM. The user approved this exact binding on 2026-09-30. Local SQLite stores only explicitly saved catalog terms and encounter counters; bundled dictionary and pronunciation data remain read-only, separate sources. The database never receives editor text, a whole sentence, or example context.

T1: A catalog-backed Save action in Hover/Deep Dive writes lemma, language, mapped meaning, source IDs, IPA if locally available, POS, pronunciation reference, timestamp and counter. A Library reads persisted entries after restart. Encounter increments only when a previously saved entry reappears as a Shadow in a new composition; UI redraw and the save composition do not count.

T2: One privacy gate controls learning writes/reads and any future cloud, logging and persistent text cache. Private leaves local input available and disables learning; Secure additionally suppresses suggestions and context. Changing mode invalidates pending learning tickets. Storage errors degrade to an unavailable Library message without stopping input. No input content logging.

Acceptance: tests for save/restart, encounter dedupe, privacy transitions, unavailable DB, and sentinel scan; CI builds native, host and tests then packages a self-contained WinUI trial. Stop here for user testing. Deferred, unapproved experience ideas: Tab-to-close, Chinese Shadow pinyin, segmentation of uncommitted mixed pinyin/English, partial pinyin prediction (`youh`), and incomplete English bilingual assistance (`don't`/`I think`). None changes frozen v0.0.5 behavior.
