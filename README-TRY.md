# Bilingual Input v0.0.1 — 体验指南

这是 Windows 原生交互原型，只在自身编辑区输入，不替换系统输入法。

## 启动
1. 从 GitHub Actions 的成功构建下载 Windows 体验包。
2. 解压整个文件夹到普通可写目录，双击 BilingualInput.exe。不要只复制 exe。
3. 首次启动会准备本地词表。无需 API Key，无需网络或安装开发工具。

本构建面向 Windows 10 2004 / Windows 11 x64。初始词表只有约 90 条自有原型映射，用于验证真实候选交互，不是商业输入法词库。

## 试一试
- 输入 youhua：候选包含“优化、油画、有话”。
- ←/→ 或 ↑/↓ 改变高亮，Space 提交高亮。
- 1–5 或鼠标选择对应候选。
- youhua + Enter 得到原文 youhua；asdfg + Enter 得到 asdfg。
- 继续输入 xuexi、gongzuo、zhongguo、nihao。
- 右上角切换浅色/深色/跟随系统。

如果系统输入法同时显示自己的候选框，将系统输入法切到英文后在本原型编辑区输入。此阶段未实现 TSF 系统输入法。

Shift+Enter 的双语 Shadow、Hover、学习收藏和 AI 不在这个里程碑；保留按键不会假装提交英文。

## 数据
输入文本仅保留在当前编辑区内存，关闭窗口不保存。词表构建文件位于本地应用数据 BilingualInput/rime；Rime 用户词典学习禁用，引擎从无插件源码构建且日志关闭。没有云端请求或账号。

## 反馈
记录操作顺序、实际结果、期待结果。不要贴真实敏感输入。请重点感受候选是否跟手、空格/Enter/方向键是否符合预期。连续试用 10–20 分钟后再决定下一阶段。
