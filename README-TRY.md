# Bilingual Input v0.0.5 — Learning 试用
Windows 10 2004+ / Windows 11 x64。完整解压后运行 BilingualInput.exe；无需 API Key。

## 先体验这四步
1. 系统键盘切英文，在编辑区逐键输入 youhua，暂不提交。鼠标停在 refine 上约 400ms，在详情中点击“☆ 收藏”；也可按 Tab 展开详情并收藏。
2. 点击“收藏词库 / Library”，查看 refine、词义、词性及再遇见次数。关闭并重开程序，确认收藏仍在。
3. 再输入一次 youhua，让 refine 自然成为 Shadow；查看再遇见次数增加。悬停和界面重绘不会重复计数。
4. “详情设置”中开启 Private Mode 后仍可本地输入，但不再读写词库。模拟安全输入区会暂时关闭候选和学习；它仅供本版测试，不代表已实现系统安全字段检测。

句子测试：粘贴 I think this 方案 is better，Tab 查看已有本地结果；Esc 后 Shift+Enter 可应用当前句英文补全。详情不会提交或改写原文；没有其他结果时不强行制造第二句。

## 试用边界
- 美式音标来自经批准的 CMUdict 25 个有限词形，经过可追踪的宽式转换；英式音标本版未收录，切换后明确提示。短语音标不拼接伪造。
- 发音使用 Windows 已安装的匹配声线。若没有对应英式/美式声线，会提示，可在 Windows 语言设置中自行添加；不会静默换口音。无网络请求，无音频磁盘缓存。
- 只收藏自有目录中可核对的词条，不保存编辑区原文或整句。真实 AI 和全系统输入法未进入本轮。
- 自有词表仍有限；输入和释义覆盖不是完整词典。旧 Primary/Shadow、上下文补全与五步引导保持。

请先试用本版；确认后才继续 v0.0.6 AI Expression。最近提及的交互与预测改进留待 v0.1.0 后讨论。
